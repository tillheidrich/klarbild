# Sample image

`lake-at-dusk.jpg` is an original illustration drawn for Klarbild as vector
shapes and rendered to JPEG. It contains no third-party material and is
covered by the repository's licence like everything else here.

It exists so that the first visit to a fresh instance can end in a printed
sheet: the "Try it with a sample photo" button in the print studio uploads
it through the normal upload path.
